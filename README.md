# 🧪 Parabank End-to-End Testing & QA Suite

## 📌 Project Overview
This repository contains a comprehensive Quality Assurance (QA) and Software Testing package for the **Parabank** web application. It covers the full testing lifecycle—from initial requirements analysis to manual test execution, bug tracking, and automated script reporting.

---

## 📂 Repository Contents

| File / Artifact | Description |
| :--- | :--- |
| `Parabank Requirements Document.docx` | Structural baseline and testing requirements documentation. |
| `PARABANK MANUAL TEST.pdf` | Comprehensive test cases and manual testing execution steps. |
| `Bug_Report_List.xlsx` | Detailed bug logging matrix with severity, priority, and steps to reproduce. |
| `parabank_automation_report.pdf` | Automated test suite execution metrics and status report. |
| `parabankfainaaall222.zip` | Complete source code archive for automated test scripts (Selenium/Java). |

## ⚙️ Tech Stack & Methodologies
* **Testing Types:** Manual Testing, Regression Testing, Functional Testing, Automation Testing.
* **Tools & Frameworks:** Java, Selenium WebDriver, Excel Bug Tracking, QA Lifecycle Standards.
